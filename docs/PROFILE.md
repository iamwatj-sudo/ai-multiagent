## Bio
ถ้าคุณยังต้องดูแล Web Forms ที่หยุดไม่ได้ และอยากทยอยย้ายไป ASP.NET Core MVC โดยไม่ต้องรื้อทั้งระบบ เว็บนี้เขียนมาเพื่อคุณ ผมกำลังทำงานแบบนี้อยู่ และจดบทเรียนไว้ที่นี่ระหว่างทาง

ผมเริ่มเขียนเว็บจาก ASP.NET ด้วย VB ได้เห็นระบบ Web Forms เติบโตจนกลายเป็นโค้ดที่ดูแลยาก ทุกวันนี้ผมเขียน C# เป็นหลัก

งานที่ทำอยู่คือใช้ AI ช่วยอ่านโค้ด legacy วางแผน และทยอยแปลงโปรแกรมเก่าเป็น ASP.NET Core MVC ทีละส่วน โดยมีคนตรวจทุกขั้น

เว็บนี้คือที่ที่ผมกำลังจดบทเรียนและวิธีคิดจากงานจริง สำหรับคนที่กำลังจะเริ่มย้ายระบบแบบเดียวกัน
